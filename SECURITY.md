# Security Policy

## Responsible Use

OmniRed is a professional offensive security skills library. All techniques described are for **authorized use only**.

### Permitted uses

- Penetration testing engagements with written authorization from the asset owner
- Bug bounty programs within explicitly defined scope
- CTF competitions
- Security research in isolated, controlled lab environments
- Red team operator training and certification preparation
- Academic and educational study of attack techniques

### Prohibited uses

- Unauthorized access to systems, networks, or data
- Attacks against infrastructure you do not own or have explicit written permission to test
- Mass scanning or targeting
- Supply chain compromise of production systems
- Any activity that violates applicable computer fraud and abuse laws

## Reporting Vulnerabilities in OmniRed

If you discover a security issue in this repository itself, report it via GitHub Security Advisories. Do not open a public issue.
